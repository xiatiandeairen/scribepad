# client-next · 模块职责与加载顺序

无构建 React 审阅面板:浏览器直接加载 React UMD + Babel standalone(见 `index.html`),无打包步骤。scribepad server 把本目录挂在 `/next/*`,入口 `index.html`。

面板已接到真实后端(sessions-scoped 契约,`types/api.ts`);`plan-app.jsx` 启动时先 `POST /api/sessions/open`(或 `GET /api/session` 兜底)拿到 `sessionId`,有会话即用 `createRealAgent`,拿不到会话才退回离线 `createMockAgent` + fixture。整体架构见 `docs/architecture.md`。

## 加载顺序即依赖顺序

`index.html` 尾部按下表顺序加载(每个 `.jsx` 挂全局符号,后加载者依赖先加载者):

| 序 | 文件                | 职责                                                                                    |
| -- | ------------------- | --------------------------------------------------------------------------------------- |
| 1  | `ds-icons.jsx`      | 图标集(`I.*`),自包含                                                                   |
| 2  | `plan-contract.jsx` | 数据契约 + 派生层:`adaptExtract()`(ExtractResult → 前端形态)、`buildPlanModel()`(引用图 / 分节 / 图例全自动派生)、`normLabel()` 标签归一 |
| 3  | `plan-fixture.jsx`  | 离线 fixture(唯一"内容"文件);有真实会话时由 `adaptExtract()` 提供同形数据,本文件仅作离线兜底 |
| 4  | `plan-mock-data.jsx`| 会话 / 历史演示数据(批注已切到后端,见 `plan-net.jsx`)                                  |
| 5  | `agent-service.jsx` | **AgentService —— AI 能力唯一出入口**:`createRealAgent(sessionId)`(fetch + ReadableStream 消费 `/agent` SSE)与离线 `createMockAgent()`,同签名 |
| 6  | `plan-net.jsx`      | **后端接线层**:会话打开、extract 重拉与重渲染入口、选区 → markdown 源锚点换算(rewrite / 批注共用)、批注 / 拍板与后端形态互转 |
| 7  | `plan-refs.jsx`     | `<Ref l="G1"/>` 标签芯片(悬停预览 / 点击跳转)、`<T s="…{G1}…"/>` token 文本、跳转总线 |
| 8  | `plan-hooks.jsx`    | 通用 hooks:持久化 state / toast / 跳转总线 / scroll-spy + 阅读进度 / 文档选区           |
| 9  | `ds-shell.jsx`      | 共享外壳:设置(主题 + 排版)、命令面板、Agent CLI 接入数据                              |
| 10 | `ds-chat.jsx`       | 对话面板(ChatPanel:消息 / 行动卡 / 会话切换)                                          |
| 11 | `ds-agent.jsx`      | Agent 配置弹窗(本地 CLI:claude -p / codex exec)                                       |
| 12 | `plan-overlays.jsx` | 浮层:选区工具条(细化 / 改写 / 批注 / 更多)、改写约束弹窗                              |
| 13 | `plan-sections.jsx` | **8 节渲染器注册表** `SECTION_RENDERERS`,统一签名 `({ sec, points, ctx })`;未注册的节走 `GenericSection` 兜底 |
| 14 | `plan-doc.jsx`      | 文档壳层:文档头 + 按 `PLAN_MODEL.sections` 经注册表分发各节 + 内嵌历史 diff             |
| 15 | `plan-right.jsx`    | 右栏三 tab:总览(审阅清单 + 前置拍板进度)/ 批注 / 历史,数量全从 `PLAN_MODEL` 派生     |
| 16 | `plan-app.jsx`      | **bootstrap + App**:开会话 → 状态编排与事件接线;`ReactDOM.createRoot('#root')` 挂载   |

样式:`ds.css`(design tokens / 外壳)→ `doc.css`(文档通用)→ `plan.css`(plan 专属,后加载覆盖)。

## 数据流(一句话)

后端 `GET /api/sessions/:id/extract` 出 `ExtractResult` → `adaptExtract()` → `buildPlanModel()` 得 `PLAN_MODEL`,各节渲染器只消费 `PLAN_MODEL`;写路径(改写 / 选区改文档)统一"改 markdown 源 → 重拉 extract 重渲染",由 `plan-net.jsx` 的重抽入口 + `agent-service.jsx` 的 `onMutated` 触发。

## 真实后端契约(sessions-scoped)

以 `types/api.ts` / `types/annotation.ts` 为准,均为整表替换语义:

- `Annotation.anchor = { srcStart, srcEnd, text }`(text = 创建时选区原文)
- `ExtractedItem.anchor = { srcStart, srcEnd }`(无 text,源文本由文档源 slice)
- `Signoff = { pointId, label, signedAt(ISO) }`
- AI 通道 `POST /api/sessions/:id/agent`:SSE `progress* → final`;`selection-op` 真改文档时 `final.mutated:true`,前端据此重拉 extract。

## 扩展点

- **替换某节形态** = 重写对应组件;**新增节** = `SECTION_DEFS`(plan-contract.jsx)加一行 + 注册渲染器;未注册的节自动 `GenericSection` 兜底,后端先行新增节类型不会白屏。
- 节标题 / 信息点容器务必保留 `data-sec` / `data-pt` / `data-screen-label` —— 跳转总线、scroll-spy、审阅清单都靠它们定位。
- 标签体系:后端稳定标签 `^[GDRPQB]\d+$`;`S`/`A`/`§` 等为前端由 ordinal 派生的导航伪标签,由 `normLabel()` 归一。悬空引用不报错,渲染为不可点的灰芯片。
