# 测试规范

## 原则

- 测试验证公开行为或稳定边界，不锁定无意义的实现细节。
- fixture 只存在于 `tests/fixtures/`，生产 UI 不加载测试或演示数据。
- 测试必须注入临时配置和状态目录，不读写用户真实 XDG 目录。
- 单测覆盖 Core、Application 和纯换算；e2e 覆盖浏览器、CLI 和真实 HTTP 边界。

## 变更门禁

- 受影响测试先跑，交付前运行 typecheck、lint、unit 和 build。
- 改动浏览器/CLI 主路径时运行对应 Playwright 用例。
- 删除兼容路径时同步删除其测试，不把旧行为转成永久回归约束。
- 失败证据必须区分实现问题、测试问题和环境限制。
